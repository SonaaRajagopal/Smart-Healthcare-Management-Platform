# 🏥 Smart Healthcare Management Platform



An AI-powered full-stack healthcare analytics platform designed to help clinicians predict chronic disease risks, monitor patient health trends, and generate explainable AI-driven insights through interactive dashboards and real-time analytics.



The platform combines advanced machine learning models, forecasting architectures, explainable AI techniques, and scalable backend services to deliver intelligent patient risk assessment and clinical decision support.



---



# ✨ Features



## 🩺 Chronic Disease Risk Prediction

Predict patient risks using advanced ML models trained on healthcare datasets.



## 📊 Real-Time Healthcare Analytics

Monitor patient health metrics and clinical trends through interactive dashboards.



## 🧠 Explainable AI with SHAP

Visualize feature importance and understand why predictions were made.



## 📈 Patient Deterioration Forecasting

Forecast future health risks using Temporal Fusion Transformer (TFT) models.



## 📂 Bulk Patient Analysis

Upload CSV datasets for large-scale patient risk evaluation.



## 🤖 AI-Generated Clinical Insights

Generate intelligent healthcare recommendations and summaries using Gemini API.



## ⚡ FastAPI REST Backend

Scalable backend APIs for real-time prediction and analytics workflows.



## 💻 Modern Healthcare Dashboard

Responsive and intuitive UI built with NextJS, ReactJS, and Tailwind CSS.

# 🧠 AI & ML Capabilities



## 🔬 Disease Prediction Models



The platform integrates multiple machine learning models for healthcare prediction and patient risk scoring:



- XGBoost

- Random Forest

- Temporal Fusion Transformer (TFT)



These models were trained and evaluated on healthcare datasets to identify disease progression patterns and predict deterioration risks with high accuracy.



---



## 📈 Model Performance



- Achieved up to **92.4% AUROC**

- Improved prediction transparency using SHAP explainability

- Enabled scalable real-time prediction workflows

- Supported intelligent clinical decision assistance



---



# 🔍 Explainable AI



The platform uses **SHAP (SHapley Additive Explanations)** to improve transparency and trust in AI-generated predictions.



Clinicians can:



- Understand feature importance

- Visualize prediction contributions

- Interpret model behavior

- Analyze healthcare risk factors

- Improve trust in AI-assisted clinical decisions



---



# 📊 Forecasting System



Using **Temporal Fusion Transformer (TFT)** models built with PyTorch Forecasting, the platform predicts future patient deterioration trends and helps clinicians identify high-risk cases early.



## Forecasting Features



- Time-series patient analysis

- Health trend prediction

- Sequential healthcare forecasting

- Temporal patient monitoring

- Early risk detection workflows
